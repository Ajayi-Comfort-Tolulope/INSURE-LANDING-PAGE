# Front-end Style Guide

## Layout

The original Frontend Mentor designs were created for the following viewport widths:

* Mobile: 375px
* Desktop: 1440px

The implementation is responsive and adapts to additional screen sizes using CSS media queries.

## Colors

### Primary

* Dark Violet: `hsl(256, 26%, 20%)`
* Grayish Blue: `hsl(216, 30%, 68%)`

### Neutral

* Very Dark Violet: `hsl(270, 9%, 17%)`
* Dark Grayish Violet: `hsl(273, 4%, 51%)`
* Very Light Gray: `hsl(0, 0%, 98%)`
* White: `#ffffff`

## Typography

### Headings

* Font Family: [DM Serif Display](https://fonts.google.com/specimen/DM+Serif+Display)
* Font Weight: 400

### Body

* Font Family: [Karla](https://fonts.google.com/specimen/Karla)
* Font Weights: 400, 700
* Base Font Size: 16px

## Responsive Breakpoints

The project uses responsive CSS media queries to adapt the layout:

* Desktop: Above 768px
* Mobile and tablet: 768px and below
* Small mobile: 375px and below

## Components

The main UI components include:

* Header and navigation
* Mobile navigation toggle
* Hero section
* Feature cards
* Call-to-action banner
* Footer
* Social media links
* Responsive buttons

## Interactive States

Interactive elements include hover states for:

* Navigation links
* View plans buttons
* How we work button
* Footer links
* Social media icons

The mobile navigation also includes open and close states controlled with JavaScript.
